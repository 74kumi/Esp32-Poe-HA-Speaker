# Historical hardware checkpoints

This directory preserves earlier source snapshots for traceability while the active design continues under `hardware/PoE-Speaker/`.

These folders are **historical references**, not the canonical source to edit for new work and not manufacturing-release packages.

The imported checkpoint set includes earlier board stages such as the first-board draft, Rev C integrated draft, Rev D eFuse draft, and a frozen Rev E review snapshot.

The active Rev E source lives at:

`hardware/PoE-Speaker/RevE/`

The frozen Rev E checkpoint may initially match the active source byte-for-byte. Once active development continues, the two trees are expected to diverge; the checkpoint should remain unchanged so it can serve as a historical reference.

When starting new engineering work, use the active source and current root-level roadmap / review documents rather than these snapshots unless you are intentionally comparing revisions.
